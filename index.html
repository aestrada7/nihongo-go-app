About audio offline

Audio uses your phone's built-in Japanese text-to-speech voice, so it works in airplane mode once a Japanese voice is on the device.

iPhone: Settings → Accessibility → Spoken Content → Voices → Japanese → download a voice (e.g. Kyoko).
Android: Settings → System → Languages → Text-to-speech → Google engine → Install voice data → Japanese.
Mac: System Settings → Accessibility → Spoken Content → System voice → Manage Voices… → Japanese → download Kyoko, then reload this page.
